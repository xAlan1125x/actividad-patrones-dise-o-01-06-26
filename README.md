# Cucumber-problemas

## Actividad de Principios SOLID

Este repositorio contiene las soluciones refactorizadas a los problemas de diseño aplicando los principios **SOLID**, utilizando **TypeScript** y automatizando las pruebas de comportamiento con **Cucumber**.

---

##  Archivos de Solución

* **`problema1-shipping.ts`**: Sistema de envíos (Aplica *Single Responsibility Principle - SRP* y *Open/Closed Principle - OCP*).
* **`problema2-documents.ts`**: Procesador de documentos (Aplica *Liskov Substitution Principle - LSP* y *Interface Segregation Principle - ISP*).
* **`problema3-switch.ts`**: Interruptor rígido (Aplica *Dependency Inversion Principle - DIP*).

---
